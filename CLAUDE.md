# georgizator

## Безопасность: никаких сторонних скриптов
Сайт публикуется на GitHub Pages и делит origin `robinsout.github.io` со всеми Pages-сайтами аккаунта, в том числе с порталом Quadern de català (`robinsout.github.io/crema-catalana/`). У сайтов с одним origin общий localStorage, а портал хранит там прогресс и **код синхронизации** — ключ к зашифрованным данным на сервере.

Поэтому **к сайту нельзя подключать сторонние скрипты**: счётчики и аналитику, виджеты, SDK соцсетей, скрипты с CDN, рекламу. Любой такой скрипт сможет прочитать данные портала. Всё, что нужно сайту, собирается в его собственный бандл.

Это правило — условие, на котором принят риск M1 из аудита безопасности портала (2026-10-04, репозиторий `robinsout/crema-catalana`, `BACKLOG.md`, S-1). Если сторонний скрипт всё-таки понадобится, сначала нужно увести один из сайтов на свой домен.
